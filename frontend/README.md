<h2 align="center"> 💻  OrbitCRM</h2>

<p align="center">Proyecto académico — Frontend</p>

OrbitCRM es un software de gestión de relaciones con clientes (CRM) diseñado para optimizar los procesos empresariales y fortalecer las interacciones con los clientes. Este sistema centraliza y organiza toda la información clave, proporcionando herramientas esenciales para un seguimiento eficaz del historial de pagos, contactos, presupuestos, propuestas comerciales entre otros.
